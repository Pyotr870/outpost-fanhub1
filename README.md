# OUTPOST 0.8

Неофициальный фан-хаб ARC Raiders. Сборка 0.8 расширяет предыдущую версию: обновлён интерфейс авторизации, добавлены кнопки OAuth Google / Discord / GitHub / Apple с реальными вызовами Supabase OAuth после настройки провайдеров, сохранены локальный гостевой режим и основные разделы сайта.

## Запуск
Открой `index.html` через локальный веб-сервер или опубликуй содержимое репозитория на GitHub Pages / другом статическом хостинге с HTTPS. Для PWA и OAuth нужен HTTPS и корректные Redirect URLs.

## Авторизация
- Email / пароль: Supabase Auth после настройки проекта.
- Google / Discord / GitHub / Apple: Supabase OAuth после настройки Client ID / Secret у провайдера и callback URL.
- Steam: отдельная серверная реализация Steam OpenID ещё не включена.
- Гостевой профиль: локально в текущем браузере, без синхронизации.

Пока Supabase не настроен, социальные кнопки показывают инструкцию, а email-вход отключён. Не вводи пароли Steam, Discord или Google в форму OUTPOST.

## Что важно
Это фан-проект, не связанный с Embark Studios. Функции друзей и интеграций без серверной настройки работают локально или как ссылки. OAuth и облачное хранилище нельзя считать активными до настройки и проверки на опубликованном домене.

## Проверки этой сборки
- JavaScript синтаксис проверен через `node --check`.
- ZIP проверяется перед выдачей.
- Полноценный сквозной OAuth-тест невозможен без OAuth credentials и опубликованного домена.
- Функции, зависящие от Supabase, не тестировались с реальным проектом.
