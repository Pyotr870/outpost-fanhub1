# OUTPOST — следующий этап

## Уже в интерфейсе 0.8
- Отдельные кнопки OAuth Google, Discord, GitHub, Apple.
- Вход/регистрация по email через Supabase Auth.
- Локальный гостевой профиль.
- Основные локальные разделы: карты, фотостудия, друзья, гардероб, галерея, интеграции, настройки, поддержка.

## Что требует настройки владельца
- Supabase URL + публичный publishable/anon key.
- OAuth Client ID / Secret каждого выбранного провайдера.
- Callback URL провайдера и Redirect URLs в Supabase.
- SQL-схема и Storage bucket.

## Серверная разработка отдельно
- Steam OpenID callback и проверка OpenID assertion.
- Публичные профили и friend requests.
- Discord bot / guild linking (с отдельными Discord permissions).
- Модерация, репорты, блокировки и rate limits.
- Автоматическая синхронизация фото только из выбранной пользователем папки, если формат и правила игры это позволяют; без чтения памяти процесса, инъекций, перехвата трафика или обхода античита.

## Публикация
Сначала HTTPS-домен и приватность, затем провайдеры OAuth, затем тестирование с отдельными аккаунтами. Платежи и монетизацию отложить до проверки прав, требований провайдеров и юридических условий; несовершеннолетнему для договоров и платежей потребуется участие родителя/опекуна.
